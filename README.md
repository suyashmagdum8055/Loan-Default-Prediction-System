The Loan Default Prediction System is a comprehensive web-based solution designed to automate and optimize the loan approval process for financial institutions. By leveraging advanced machine learning algorithms, the system provides accurate, real-time risk assessment for loan applicants

# Loan Default Prediction System

An AI-powered web application for predicting loan default risk using Machine Learning (XGBoost). This system helps banks and financial institutions make faster, more accurate lending decisions.

## Features

- User authentication system (Login/Signup)
- Real-time loan default prediction
- Interactive dashboard with analytics
- 2D and 3D risk visualizations
- Prediction history tracking
- REST API for integration
- Visitor statistics tracking

## Tech Stack

### Backend
- Flask (Python web framework)
- PostgreSQL (Database)
- XGBoost (Machine Learning model)
- Scikit-learn (Data preprocessing)

### Frontend
- HTML5, CSS3
- JavaScript
- Plotly (Interactive charts)
- Font Awesome Icons

### Machine Learning
- Model: XGBoost Classifier
- Features: 25 financial and personal attributes
- Accuracy: 85-95% on test data
- Threshold optimization for balanced predictions

## System Requirements

- Python 3.8 or higher
- PostgreSQL 12 or higher
- 4GB RAM minimum
- 2GB free disk space
